# CLAUDE.md

This directory is the **motion-graphic** agent skill.

- **Making a video:** use the skill. Follow `SKILL.md` and build the film in its own project folder, outside this directory.
- **Changing the skill:** read `AGENTS.md` first. It has the layout, the invariants (determinism, no per-project installs, never overwrite user work) and the smoke test to run before committing.

Commits use `<type>: <description>` (feat, fix, docs, refactor, test, chore, perf, ci).
